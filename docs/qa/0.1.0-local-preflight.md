undersized HFS+ image for this universal binary. The committed release script
creates, verifies, mounts, and inspects the fixed-size image successfully.

The updater archive and `.sig` were exercised with a password-protected,
one-time key under `/tmp`. The signature verified against the exact archive;
an appended `tamper-canary` archive was rejected. The temporary private/public
key files were unlinked and their temporary directory removed. This signature
does **not** match the repository's development public key and is not a
release asset.

The app bundle has no Developer ID/notarization and `codesign --verify` reports
it as unsigned; this matches the documented unsigned preview state and is not
an operating-system publisher PASS.
