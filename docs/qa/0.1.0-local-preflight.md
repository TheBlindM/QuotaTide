## Native system-proxy regression

The desktop manifest had disabled reqwest default features without restoring
the optional `system-proxy` backend. On this Mac, direct TCP connection to the
Codex origin timed out while the operating-system proxy was enabled, so the
running app could refresh Radar but not the current Codex account.

The candidate explicitly enables reqwest `system-proxy`, backed by macOS
SystemConfiguration and the Windows registry. A contract test prevents future
manifest regressions. After the fix:

- the explicit ignored live-account test completed in 2.02 seconds;
- the returned window was the strict current 604800-second Codex window;
- SHA-256 of the Codex-managed `auth.json` matched before and after the test;
- a newly built release-profile app refreshed both Codex and Radar at startup
  with zero consecutive failures and no public error;
- the database contained one single-account stream, at least one observation,
  one quota epoch, and seven ledgers for that current upstream window;
- after roughly three minutes hidden, the app process reported `0.0%` CPU and
  48,280 KiB RSS.

The Mac was later unlocked. The current-source tray window and settings were
observed, but notification delivery, system permission dialogs, VoiceOver, and
installation from the DMG were not exercised. These facts are local regression
evidence only, not a formal matrix PASS or an installed-final-artifact PASS.

## Browser-rendered UI regression

The production components were rendered at the tray window's 420 × 680
viewport without a separate prototype. Local browser inspection covered:

- Chinese and English warning dashboards, including the complete current
  seven-day table and active Reset Radar card;
- light glass styling and the deterministic dark opaque fallback;
- account, quota, alert, and privacy settings navigation;
- rejection of a seven-day policy total above 100%, with the save action
  disabled and an actionable message;
- 200% font scaling through the complete scrollable dashboard and settings
  surfaces, with no horizontal overflow;
- structured preview quota and Radar inputs through the production projection
  path, including English app-owned copy while `zh-CN` independently formats
  dates and ordinary weekday labels.

This pass found and fixed two issues: preview-only reset/Radar values were only
partially localized, and narrow headers truncated the settings subtitle at
200% font scale. Unit coverage now protects the structured projection and
interface/format-locale boundary. A real Chrome gate requires both Radar links
and checks that overview plus Account, Quota, Alerts, Privacy, and footer
controls are fully inside their scroll viewport when focused at 200%. Browser
rendering does not prove native material composition, taskbar anchoring,
VoiceOver, or notification behavior.

## Unlocked native app smoke

The universal `.app` built from `fe06429` was launched on the development Mac
and inspected through the native macOS accessibility tree and screenshots:

- a startup refresh that completed while the dashboard listener handshake was
  unresolved no longer left the UI stuck on “正在刷新”; the title returned to
  “Codex 额度 · 正常” and the manual refresh control became available;
- the policy date moved to 07/31 without an app reinstall, and the current
  seven-day window was 07/29–08/04 rather than a rolling “last seven days”;
- the current workday displayed base 16% plus 12% carry, for an effective 28%
  limit, while the account showed 6% used and 22% still available today;
- the account, quota, alerts, and privacy settings exposed native-accessible
  headings, tabs, fields, checkboxes, and actions. The auth path was summarized
  rather than disclosed, and no setting or Codex-managed file was modified;
- the live tray-sized window showed the intended translucent rounded material,
  seven-day ledger, Reset Radar attribution, recent alert, and source-health
  timestamp.

Two deterministic UI regressions protect this smoke result: one keeps local
state reconciliation active while native event listeners are still attaching,
and one reprojects the ledger when the configured policy timezone crosses
midnight. The reconciliation loop only reads the local Tauri state; it does not
issue extra Codex or Radar network refreshes and therefore preserves the
one-hour collection cadence.
