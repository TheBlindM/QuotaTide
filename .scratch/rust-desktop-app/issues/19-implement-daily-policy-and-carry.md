# 19 — 实现每日策略与工作日结转

**What to build:** 让用户在额度设置中配置七日策略模板、策略时区和工作日
结转，并让概览用可解释、历史稳定的今日实际上限计算提醒状态。

**Blocked by:** 18 — 建立当前七日额度账本

**Status:** completed

- [x] 默认七日策略为周一至周日 `16/16/16/16/16/10/10`，UI 支持逐日编辑。
- [x] 七个基础额度必须非负且总和不超过 100%；无效输入不能产生部分保存。
- [x] 策略时区使用有效 IANA timezone，决定自然日、星期、策略 revision
  生效日和按日提醒归属。
- [x] 修改基础额度、结转开关或策略时区会追加 revision，今天及未来使用新
  revision，已完成日期继续引用历史 snapshot。
- [x] 开启结转时，已确认未用工作日额度平均分配给同一自然周内后续工作日，
  不进入周末且不跨自然周。
- [x] 未知日期不能产生结转；已经分配给某日的份额不能再次分配。
- [x] 工作日超用只标记当天超额，不产生负结余，也不扣减后续工作日基础额度。
- [x] 今日实际上限明确展示基础额度与结转额度，daily ledger 持久化对应
  policy revision、base units 和 carry units。
- [x] 当日使用达到今日实际上限 80%/100% 时产生稳定 threshold transition，
  但不阻断任何 Codex 操作。
- [x] 属性测试证明历史不变、结转守恒、周末隔离、自然周隔离、unknown 规则
  和七日基础总量约束。
