# 选择 Rust 跨平台桌面技术栈

## Question

基于官方一手资料比较 Tauri 2 与仍具现实可行性的纯 Rust UI 方案，决定哪个技术栈最适合同时交付 macOS 与 Windows 托盘应用。结论必须覆盖 Rust 核心占比、WebView/渲染能力、托盘窗口支持、包体与资源、插件成熟度、测试能力、维护风险，并在 `docs/research/desktop-stack.md` 留下带引用的研究资产和明确推荐。
