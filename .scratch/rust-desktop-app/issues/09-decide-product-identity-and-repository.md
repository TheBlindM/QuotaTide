# 确定产品身份与开源仓库

## Question

决定公开产品名、中英文显示名、GitHub `owner/repo`、bundle identifier、
Windows publisher/display metadata、可执行文件与数据目录名称、版权持有人、
SECURITY 联系方式和 updater endpoint。名称必须适合开源发布，不能暗示这是
OpenAI 官方产品，也不能在首次公开 Release 后随意改变持久身份。
