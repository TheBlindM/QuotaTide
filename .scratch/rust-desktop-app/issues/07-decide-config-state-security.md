# 决定配置、状态与本地安全模型

## Question

决定七日策略、账号路径、收发件配置、提醒偏好、历史快照、凭证引用和诊断日志的持久化模型；明确配置版本迁移、原子写入、凭证缺失、文件权限、脱敏导出与损坏恢复行为。用户已经决定 SMTP 密码不进入普通配置文件、历史策略不回算。
